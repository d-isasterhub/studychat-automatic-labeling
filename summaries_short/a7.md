**Context**
Students build a simple autocomplete system by training a character-level RNN to predict the next character in a text sequence.

**Learning Objectives**

* Understand character-level RNNs and sequential modeling
* Implement an RNN forward pass in PyTorch
* Learn hidden state propagation and embeddings
* Train on sliding-window character datasets
* Generate text from a trained model
* Tune hyperparameters and analyze effects
* Compare synthetic vs. real-world data performance

**Prerequisites**

* Basic Python
* Familiarity with PyTorch (tensors, modules, training loops)
* Neural network fundamentals (loss, gradients, backpropagation)
* Conceptual understanding of RNN recurrence

**Tasks / Deliverables**
Complete missing code in a provided PyTorch file:

* **Model**: initialize parameters, implement forward pass
* **Data**: create char-index mappings, encode text, split data (90/10)
* **Training**: implement loop (loss, backprop, optimizer, logging), tune hyperparameters
* **Evaluation**: implement test loop
* **Text generation**: implement function to sample next characters with temperature
* **Experiments**: train on synthetic alphabet data and real text (`warandpeace.txt`)
* **Submission**: short report (1-2 paragraphs) analyzing results, loss/accuracy, temperature effects, and generated text

**Provided Materials**

* Partially completed PyTorch code (`rnn_complete.py`)
* Dataset class (`CharDataset`)
* Partial RNN implementation (`CharRNN`)
* Training/sampling framework (to complete, not redesign)
* Two datasets (alphabet + War and Peace)
* Hyperparameter tuning guidance
