**Assignment Summary (Condensed)**

Students apply standard machine learning workflows in Python using two datasets (synthetic slime growth for regression and chronic kidney disease for classification). Narrative context is illustrative only.

**Objectives**

* Use Pandas for data loading, inspection, and preprocessing
* Use scikit-learn for:
  * Regression (linear, polynomial)
  * Classification (Logistic Regression, SVM, k-NN, Neural Network)
* Perform full ML workflow: train/test split, training, evaluation, interpretation
* Compare models empirically and report results scientifically

**Prerequisites**

* Basic Python programming
* Familiarity with listed ML algorithms
* Understanding of supervised learning (features, labels, training/testing)

**Tasks / Deliverables**

* Load and preprocess datasets

**Regression (slime dataset):**

* Split features/labels and create train/test split
* Train linear and polynomial (degree 2) regression models
* Make predictions
* Explain model score
* Extract coefficients and express learned equation in LaTeX
* Perform 5-fold cross-validation and interpret results

**Classification (CKD dataset):**

* Train and evaluate Logistic Regression, SVM, k-NN, Neural Network
* Perform 5-fold cross-validation; report mean and standard deviation
* Compare models, identify best, justify conclusions
* Test ≥3 neural network configurations and analyze parameter effects

**Materials**

* Slime and CKD datasets
* Documentation for Pandas and scikit-learn
* Fixed parameters for reproducibility (e.g., `random_state=42`, 5-fold CV)
