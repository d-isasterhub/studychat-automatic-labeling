**Context / Story**
Fictional internship at a messaging app company ("WordWizard / ChatCast") to build an autocomplete system using BFS, DFS, and UCS on a character-based prefix tree derived from a text dictionary.

**Learning Objectives**

* Build and traverse a prefix tree from text data
* Implement BFS, DFS, and UCS in Python
* Apply search algorithms to autocomplete
* Compare search strategies in terms of output order, quality, and use cases

**Prior Knowledge**

* Basic Python (syntax, loops, functions, data structures)
* Conceptual understanding of BFS, DFS, UCS
* Trees, stacks, queues, priority queues

**Tasks / Deliverables**

* Implement `build_tree` for character-based tree construction
* (Optional) Extend `Node` class for suggestion methods
* Implement `suggest_bfs`, `suggest_dfs`, `suggest_ucs`
* Provide brief (1-2 sentence) code explanations
* Explain recursive vs stack-based DFS intuition
* Compare BFS, DFS, UCS outputs (order, suggestion types, trade-offs)

**Provided Materials**

* Example tree and autocomplete explanation
* Input text files (`genZ.txt`, `test.txt`)
* Starter code (`main.py`, `utilities.py`)

  * `main.py`: run setup
  * `utilities.py`: file reading and GUI (`suggest_in_gui`, `create_gui`)
* Pre-built GUI and document-loading tools
