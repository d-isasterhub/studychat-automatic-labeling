**Context**
Students build a character-level sentence autocomplete feature for a messaging app using statistical n-gram language models (not neural models).

**Learning Objectives**

* Understand mathematical principles of n-gram language models
* Implement a character-level n-gram model from scratch:
  * Build frequency tables
  * Compute conditional probabilities
  * Predict the most likely next character
* Analyze effects of n and corpus choice on performance and efficiency

**Prerequisites**

* Basic Python (functions, dictionaries, lists, file I/O)
* Basic probability (joint vs. conditional)
* Theoretical understanding of n-grams
* Ability to read simple mathematical notation

**Tasks / Deliverables**

* Implement in `NgramAutocomplete.py`:
  * `create_frequency_tables(document, n)`
  * `calculate_probability(sequence, char, tables)`
  * `predict_next_char(sequence, tables, vocabulary)`
* Write a report explaining:
  * Intuition and formulas for each function
  * Manual n-gram example: frequency tables, probability calculations, and next-character prediction
* Run experiments with different corpora and n values and analyze performance

**Provided Materials**

* Starter code: `NgramAutocomplete.py`, `main.py` (optional), `utilities.py` (no changes)
* Explanations of frequency tables, probability estimation, and Bayesian networks
* Example corpora for experiments
