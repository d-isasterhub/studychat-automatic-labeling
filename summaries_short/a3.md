**Context**
Students preprocess messy Chronic Kidney Disease (CKD) data from two sources (numerical and categorical) to prepare it for machine learning.

**Learning Objectives**

* Data cleaning with pandas
* Handling messy and multi-source datasets
* Encoding categorical + normalizing numerical features
* Using and critically evaluating LLM support (e.g., ChatGPT)

**Prerequisites**

* Basic Python
* Jupyter notebooks
* Tabular data fundamentals

**Tasks / Deliverables**

* **Data preprocessing (pandas):** load, inspect, deduplicate, merge datasets, handle missing values, sort by label, encode categorical features, remove outliers, normalize features, drop irrelevant columns, export (CSV/JSON)
* **Conceptual explanations:** dataset structure, missing IDs across datasets, merge implications, encoding choices, feature selection decisions
* **LLM-assisted tasks:** markdown table conversion, pandas code generation (e.g., renaming), SQL-to-pandas translation + explanation
* **Reflection:** risks of LLM hallucinations and validation; explanation of generated code

**Materials**

* Two dirty CKD datasets (numerical + categorical)
* pandas documentation links
* CKD dataset description
* Example SQL query for LLM conversion
