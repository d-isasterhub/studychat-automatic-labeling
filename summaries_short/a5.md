**Summary**

Students learn PyTorch through notebook-based exercises, progressing from tensor operations to training neural networks on the Iris and Titanic datasets for classification tasks.

**Learning Objectives**

* Manipulate tensors and understand PyTorch workflows
* Implement, train, and evaluate an MLP model
* Analyze and tune hyperparameters

**Prerequisites**

* Python programming and NumPy
* Basic ML concepts (classification, loss, optimization)
* Neural networks and backpropagation

**Tasks / Deliverables**

* Tensor operations: creation, manipulation, and shape reasoning (incl. broadcasting)
* Train and evaluate an MLP on Titanic: preprocessing (missing values, encoding, normalization, splitting), Dataset/DataLoader usage, model setup (incl. GPU), training/testing loops, loss plotting, accuracy reporting
* Hyperparameter tuning (≥5 configs) with explanation, results table, and analysis

**Materials**

* Scaffolded notebook with explanations (tensors, logistic regression)
* Complete examples (GPU usage, broadcasting, Iris classification pipeline)
* Partial implementations with TODOs
* External PyTorch documentation
